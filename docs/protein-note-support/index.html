主な機能

📸

AI食品認識

写真を撮るだけでAIが食品を識別し、栄養素を数秒で自動推定。複数の食品も一括で認識・記録できます。

🥩

4大栄養素管理

タンパク質・カロリー・脂質・炭水化物をまとめて記録。696種の食品データベースから素早く検索。

💪

筋トレ記録

60種以上のエクササイズに対応。重量・レップ・セットを記録し、テンプレートやレストタイマーも搭載。

🤖

AIアドバイス

食事内容やトレーニング履歴をAIが分析し、栄養バランスやトレーニングメニューの改善を提案します。

🎙️

ボイスアシスタント

「鶏むね肉200g食べた」と話すだけで記録完了。筋トレ中でもハンズフリーで食事・トレーニングを記録。

📊

統計・グラフ

日別・週間・月間・年間の栄養摂取量や体重推移をグラフで可視化。目標達成率も一目で確認。

👥

友達とつながる

フレンドコードで友達を追加。ワークアウトを共有してリアクションを送り合い、一緒にモチベーションUP。

⚖️

体重・歩数管理

体重の推移をグラフで確認。HealthKit連携で歩数・消費カロリーも自動取得。ダイエット管理にも最適。

🏆

バッジ・ストリーク

記録の継続でバッジを獲得。ストリーク（連続記録日数）でモチベーションを維持できます。

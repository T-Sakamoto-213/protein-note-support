筋トレ記録の使い方

フィットネスタブ →「筋トレ」から、種目ごとのセット・重量・レップを記録できます。約60種目を収録し、部位は胸・背中・肩・腕・脚・腹＋有酸素に分かれています。

ワークアウトを記録する

  1. フィットネスタブ →「筋トレ」→ ワークアウト記録を開始します。
  2. 種目を選び、重量・レップ数を入力してセットを追加していきます。
  3. セット間は休憩タイマーで管理（60 / 90 / 120 / 180秒のプリセット、初期値90秒）。
  4. 終了すると履歴に保存され、ワークアウト詳細から振り返れます。

「ベンチ80キロ10回」のように音声で記録することもできます（ボイスアシスタントと共通・無料1日1回）。

テンプレートで毎回の入力を省く

よく行うメニューはテンプレートにしておくと、ワンタップで種目一式を呼び出せます。

  • 既製テンプレート8種 — 上半身プッシュ / 上半身プル / 脚の日 / 全身 / 自重トレーニング / ダンベルのみ / 腹筋集中 / HIIT
  • カスタムテンプレート — 自分のメニューを保存（無料3個まで・プレミアム無制限）

分析・統計

  • 統計画面（筋トレタブ） — 合計セット数・合計ボリューム・セッション数・週あたりの回数を週 / 月 / 年で確認
  • 部位別バランス — 鍛えた部位の偏りを可視化（部位別の詳細分析・推移はプレミアム）
  • AI筋トレアドバイス — トレーニング内容に基づくAIからの提案。無料プランは広告視聴で利用、プレミアムは1日3回

仲間と続ける（コミュニティ）

  • フィットネスタブ →「仲間」から、フレンドコードで友達を追加（無料10人まで・プレミアム無制限）
  • 友達のワークアウトにリアクションを送り合えます
  • 自作のテンプレートはテンプレートシェアで共有できます（無料 月3回・プレミアム無制限）

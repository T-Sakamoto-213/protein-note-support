はじめてガイド

プロテインノートはアカウント登録なしで使い始められます。初回設定は約1分。この記事ではダウンロードから最初の記録までを解説します。

初回設定の流れ（約1分）

アプリを最初に開くと、あなた専用のタンパク質目標をつくるための質問が続きます。すべて後から設定画面で変更できます。

  1. 目標を選ぶ — 減量 / 筋肉をつけたい / 体重を維持 / 健康的に過ごす の4択。
  2. 食事パターンを選ぶ — 3食しっかり / 朝抜き / 不規則 / 間食多め。
  3. 身体情報を入力 — 現在の体重（目標体重は任意）。
  4. 活動量を選ぶ — ほぼ運動なし〜非常にハード（1日2回トレーニング等）の5段階。
  5. プランの確認 — 1日のタンパク質目標などが自動計算されて表示されます。計算は厚生労働省の食事摂取基準と国際スポーツ栄養学会（ISSN）の推奨値に基づきます。
  6. 通知の設定（任意） — 食事リマインダーなどを受け取るか選びます。
  7. プレミアムの案内 — 初月無料で試すか選べます。スキップしてもすべての基本機能は無料で使えます。
アカウント登録は不要です。ゲストモードのデータは端末内に保存されます。機種変更してもデータを残したい場合は、設定画面の「データを保持してアカウント登録」からいつでもアカウントを作成できます（データ管理・機種変更参照）。

画面の見かた（5つのタブ）

タブできること
ホーム今日のタンパク質・カロリー・PFCの達成状況、AIコーチからのアドバイス、体重や習慣のカードをまとめて確認
フィットネス「歩数 / 筋トレ / 仲間」を切り替え。筋トレ記録・歩数・コミュニティの入口
中央の記録ボタンタップすると「何を記録する？」が開き、食事・筋トレの記録を開始
カレンダー月間の記録を日付ごとに一覧。日次詳細・月間分析へ
設定目標・通知・コーチの性格・データ管理・プランなど

最初の記録をしてみる

  1. 画面下・中央の記録ボタンをタップします。
  2. 「何を記録する？」から方法を選びます。最初は「食品を検索して記録」か「写真で記録」が簡単です。
  3. 記録するとホームのタンパク質リングに反映され、AIコーチが反応してくれます。

5つの記録方法の詳しい使い分けは食事記録の使い方を参照してください。

続ける仕組み：ストリークとバッジ

  • ストリーク — 記録を続けた連続日数。3 / 7 / 14 / 30 / 50 / 100 / 365日のマイルストーンがあり、節目にはお祝いが表示されます。
  • バッジ — 初めての記録、目標達成、連続記録、歩数などの達成でもらえます（バッジ一覧画面で確認）。
  • ストリーク保護 — 1日欠けてもストリークを守る仕組みがあります（AIコーチの使い方内で解説）。

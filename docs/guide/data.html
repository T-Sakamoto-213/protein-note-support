データ管理・機種変更

記録データの保存のしくみ、機種変更時の引き継ぎ、ヘルスケア連携、エクスポート、退会までをまとめます。

ゲストモードとアカウントの違い

ゲストモードアカウント登録後
データの保存先端末内のみクラウドに保存
機種変更・アプリ削除データは失われるログインすれば引き継がれる
登録方法—設定 →「データを保持してアカウント登録」（Apple / Google連携に対応）

機種変更でデータを引き継ぐ

  1. 旧端末でアカウント登録を済ませておきます（設定 →「データを保持してアカウント登録」）。
  2. 新端末にアプリをインストールし、同じアカウントでログインします。
  3. 記録データが自動で引き継がれます。
注意: フォトログ（食事写真）はプライバシー保護のため端末内にのみ保存されており、機種変更では引き継がれません。栄養素などの記録データ自体はアカウントがあれば引き継がれます。

ヘルスケア（HealthKit）連携

iPhoneのヘルスケアと連携すると、歩数を自動で取得できます。体重もヘルスケアから読み取れます（体重入力時に許可を求められます）。

連携がうまく動かないときは、iPhoneの「設定」→「プライバシーとセキュリティ」→「ヘルスケア」→「プロテインノート」で読み取り許可を確認してください。歩数目標は設定画面の「歩数目標（HealthKit）」から変更できます。

CSVエクスポート（プレミアム）

設定 → データ管理 →「食事記録をCSVエクスポート」から、記録をCSVファイルとして書き出せます。期間（直近◯日分 / 全期間）を選べるので、スプレッドシートでの自己分析や記録のバックアップに使えます。

通知設定

設定 → 通知設定から、次のリマインダーを個別にオン/オフ・時刻設定できます: 食事リマインダー（朝・昼・夜）/ 目標チェック通知 / ストリーク維持通知 / 週間レポート通知。

テーマ（ライト/ダーク）

設定 → アプリ設定からライトモード / ダークモードを切り替えられます。

退会（アカウント削除）

  • 設定画面下部の「退会」からアカウント削除をリクエストできます。サーバーに保存されたデータは合理的な期間内に削除されます。
  • ゲストモードの場合は「ゲストモードを終了」が表示されます。ゲストのデータは端末内のみのため、アプリを削除すれば消去されます。
  • プレミアム契約中の方は、退会とは別にサブスクリプションの解約も必要です（アプリ削除・退会だけでは解約されません）。
